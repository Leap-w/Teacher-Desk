# TeacherDesk

面向高中班主任的综合工作台（Web / PWA，本地优先）。以班级日常事务为核心，覆盖学生档案、座位编排、课程表、请假审批、值日管理、假期管理、班费管理等工作场景；课程表另有两个 macOS 桌面小组件（只读）。数据**本地优先 + 云端同步**：不登录时完全按本地模式运行，登录后同一账号可在换设备 / 换浏览器时接着用同一份数据（腾讯云 CloudBase，唯一的云同步方案）。

> **开发交接**：业务规则、技术架构与开发约束见 [docs/开发手册.md](docs/开发手册.md)；后续规划见 [docs/roadmap.md](docs/roadmap.md)；进展评估与待拍板事项见 [docs/开发计划.md](docs/开发计划.md)；每个版本的完整变更记录见 [docs/CHANGELOG.md](docs/CHANGELOG.md)。

## 核心功能

### 班级管理

**学生档案**（`/students`）

- 学生信息管理：详情 / 新增 / 编辑 / 软删除，学号唯一
- 搜索与筛选、三种排序（默认 / 首字母 / 随机）
- 批量修改与批量删除
- Excel 批量导入，弹窗内可直接下载模板
- 家庭地址与返家范围、昌都市内亲属与亲戚关系
- 重名学生识别（按身份证尾号消歧）

**座位管理**（`/class/seats`）

- 固定教室布局：7 排 × 9 列、3-3-3 分列、63 座
- 教师 / 学生双视角，座位图一屏自适应 + 应用内「铺满」/ 浏览器全屏
- 拖拽换座（交换 / 移入空位）、换座日志与「本次调整」摘要
- 座位方案：新建 / 切换 / 重命名 / 复制 / 删除 / 方案对比
- 自动排座：约束求解、换一种排法、撤销
- 座位约束与约束检查（不能同桌 / 不能相邻 / 高个坐前排 / 班委集中）
- 学生定位、长按座位信息卡
- 导出「PDF · 双视角」与「Excel · 两个视角」，座位表 Excel 导入

**请假管理**（`/class/leave`）

- 请假申请 → 审批 → 离校 / 返校登记一条线
- 按「天 + 上午 / 下午」记录时段并自动算时长
- 搜索与状态筛选；学生被删除后记录保留（姓名快照）

**值日管理**（`/class/duty`）

- 建值日组、设「起点日期 + 起点组」，按天自动轮换
- 今日值日与接下来 7 天；周末是否排值日可开关
- 值日组 Excel 导入

**假期管理**（`/class/holiday`）

- 自定义假期（名称 / 起止 / 备注），周末自动出现
- 离校 / 留校二态登记：**有回家记录 = 离校，没有回家记录 = 留校**，两数之和恒等于在读人数
- 三张统计卡片（离校 / 留校 / 昌都市外离校）即筛选入口，再点一次取消筛选
- 名单顶部「全选」（三态：未选 / 部分选中 / 全部选中），只作用于当前筛选结果
- 学生级假期备注（离校与留校都能写），与筛选 / 批量登记 / 导出同一条链路
- 按姓名 / 性别 / 家庭所在地 / 市内亲属筛选，多选后批量设为离校 / 留校
- 导出名单（九列，不含已退档）

**macOS 桌面小组件**（[macos/](macos/README.md)，v3.7.0）

- **今日课程**（Small / Medium）：当天全部课程，科目为主、节次为辅；没课时明说「今天没有安排课程」
- **一周课程表**（Large）：`星期 × 节次` 完整课表，今天那一列轻量高亮，空格子画「—」
- 完全只读：数据来自课程表快照（`widget-snapshot.json`）；小组件不联网（沙盒里**没有网络 entitlement**）、不登录、不写业务数据
- 点小组件 → 打开 TeacherDesk PWA；改课程表后快照自动更新，也可点「同步并刷新」立即重画
- 构建、安装、数据链路与取舍见 [macos/README.md](macos/README.md)

**班费管理**（`/class/fund`）

- 班级电子账本：收入 / 支出流水，分类与自定义支出类型
- 收费批次：按人头收费，名单跟着学生档案走（转来的学生会自动出现）
- 余额与统计（全部 / 本月 / 本学期），余额由流水实时算出
- 导出「PDF · 收支账目」与「Excel · 收支与缴费」

### 工作管理

**课程表**（`/work/schedule`）

- 手机用星期切换条 + 分日列表，电脑用完整周视图（周一 ~ 周日）
- 新增 / 编辑 / 删除课程，时段冲突会拦下，支持临时代课标记
- 课程时间在「我的 → 设置 → 教学设置」里配置，Excel 导入课表

**工作清单**（`/work/works`）

- 待完成 / 进行中 / 已完成，按今日 / 本周 / 稍后 / 逾期分组
- Excel 导入

### 课堂工具

`/my/classroom`（首页的课堂工具入口进入）

- 随机点名：全班 / 男生 / 女生 / 今日值日组
- 课堂计时器：预设 1 / 3 / 5 / 10 分钟 + 自定义
- 抽签：从现有值日组里随机抽一组

### 数据与同步

`/my/tools`（「我的 → 系统设置 → 数据与同步」）

- 导出数据：一键下载 JSON 备份
- 导入数据：合并式导入，先给逐块预览再写盘
- 云同步：账号登录 / 立即同步 / 退出登录，状态与云端返回的错误原因原样显示
- 顶栏同步按钮（登录后每一页都在，点一下就同步一次），上次同步时间显示在云同步那一行
- 自动同步四个触发点：应用启动、本页改动之后、重新联网、页面回到前台

### 我的

`/my`：Hero（个人资料与编辑）、工作时光、系统设置（深色模式 / 教学设置 / 班级设置 / 时光中心 / 数据与同步）、关于（当前版本 / GitHub / 检查更新）。

## 技术栈

- **框架**：Vue 3.5 + TypeScript 5.8（strict）
- **构建**：Vite 7
- **状态管理**：Pinia 3
- **路由**：Vue Router 4
- **样式**：UnoCSS（presetWind3）+ `src/styles/theme.css` 设计令牌
- **图标**：lucide-vue-next（按需引入）
- **后端**：腾讯云 CloudBase（`@cloudbase/js-sdk`，内置文档型数据库 + 账号密码鉴权）
- **PWA**：vite-plugin-pwa（autoUpdate）
- **部署**：腾讯云 CloudBase 静态网站托管
- **测试 / 规范**：Vitest 3、ESLint 9（flat）、Prettier 3

TeacherDesk 采用**本地优先架构**：数据以本地存储为主要工作面，通过 Repository / Store / Sync 层连接 CloudBase。

组件全部自行封装（不引入 UI 组件库），Apple 风格：主色高原青 `#4A8C94`、卡片圆角 24px、毛玻璃、柔和阴影；Design Tokens 统一维护在 `src/styles/theme.css`（含深色覆盖）。PWA 生产构建后可安装到桌面 / 主屏，Service Worker 预缓存支持离线打开。

## 本地开发

需要 Node.js >= 20.19。

```bash
npm install
npm run dev         # 开发服务器 http://localhost:5173（同网手机可开 http://<本机 IP>:5173）
```

常用命令：

| 命令                 | 说明                                                     |
| -------------------- | -------------------------------------------------------- |
| `npm run dev`        | 开发服务器                                               |
| `npm run build`      | 类型检查 + 生产构建 + 生成深链占位                       |
| `npm run preview`    | 预览生产构建（验证 PWA 安装用）                          |
| `npm run test`       | 常驻回归测试（40 个文件 974 项，离线可跑，不需要云环境） |
| `npm run test:watch` | 同上，改一处跑一次                                       |
| `npm run type-check` | TypeScript 类型检查（vue-tsc --noEmit）                  |
| `npm run lint`       | ESLint 检查并自动修复                                    |
| `npm run format`     | Prettier 格式化                                          |
| `npm run deploy`     | 构建并发布到 CloudBase 静态网站托管（需先 `tcb login`）  |

交付前置的验证链是 **prettier / vue-tsc / eslint / test / build** 五项，CI 跑同一条链（`.github/workflows/ci.yml`）。

## 部署

Web / PWA 发布到**腾讯云 CloudBase 静态网站托管**——与数据库、鉴权用同一个环境（`teacher-desk-d6gdsgqb8f9dc13d2`）。

- 线上地址：<https://teacher-desk-d6gdsgqb8f9dc13d2-1454430270.tcloudbaseapp.com>
- 配置在 `cloudbaserc.json`（`framework: vite` / `buildCommand: npm run build` / `outputDir: dist` / `deployPath: /`）。

```bash
npm install -g @cloudbase/cli   # 一次性；也可免安装，把 tcb 换成 npx -y -p @cloudbase/cli tcb
tcb login                       # 一次性：CLI 打开浏览器授权页
npm run deploy                  # = tcb deploy：安装依赖 → 构建 → 上传产物
```

两条纪律：

- **必须走 `npm run build`**：全应用是历史路由，构建的最后一步 `node scripts/hosting-routes.cjs` 会为每个已知路径生成 `<路由>/index.html` 占位（当前 26 条），静态托管才能直接命中深链、刷新不 404。只上传旧 `dist/` 会让新页面 404。
- **发布前置（本环境已就绪，换环境时照做）**：① 静态网站托管已开通；② 静态托管域名要在控制台「环境配置 → 安全来源」里——**不在其中时页面能打开，但登录与同步会被云端拒**。

### 云端同步（可选）

不配也能用：不登录时应用完全按本地模式运行。要用同步，先做两件事：

1. **云侧准备（一次性，在 CloudBase 控制台做）**：开启**用户名密码登录** → 在「身份认证 → 用户管理」里**把账号建出来**（应用不提供注册）→ 建一个名为 `teacherdesk` 的集合 → 权限选**「仅创建者可读写」**。
   - ⚠️ **不要用「匿名登录 + 所有人可读」**：一个账号里装的是全班学生的姓名 / 学号 / 家庭住址 / 请假与返家记录。
   - ⚠️ **建账号时关掉「邮箱验证」**：应用里没有输入验证码的地方，开着它账号会停在未验证、登录必被拒。
2. **应用内登录**：点**顶部右侧头像**（或「我的 → 系统设置 → 数据与同步」）→ 用户名 + 密码。

> ⚠️ **第一次登录请在「录了真实数据的那台设备」上做，并先导出一次备份。**

两条踩过的坑：报 `FIRST_LOGIN_PASSWORD_UPDATE_REQUIRED` = 环境开着「首次登录强制改密」，而应用里没有改密码的界面，关掉策略即可（`tcb env login set -e <环境ID> --first-login-update false`）；报 `Failed to fetch` 之类 fetch 直接抛 = 域名不在**安全来源**里。

要指向别的环境：`VITE_CLOUD_ENV_ID=<环境ID> npm run dev`（默认值写在 `src/config/index.ts`）。

同步口径与边界（最后写入胜出、无删除传播、本地清空 ≠ 云端清空、首次同步遇两边都有数据时报冲突不覆盖）见 [docs/开发手册.md](docs/开发手册.md) §9.20 / §9.21。
