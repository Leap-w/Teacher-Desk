# TeacherDesk

面向高中班主任的综合工作台（Web / PWA，本地优先）。以班级日常事务为核心，逐步覆盖学生档案、座位编排、课程表、请假审批、值日管理、周末管理等场景；后端规划腾讯云 CloudBase + PostgreSQL，后续支持 macOS Widget。

> **开发交接**：当前状态、业务规则、技术架构与开发规范的详细说明见 [docs/开发手册.md](docs/开发手册.md)；阶段规划见 [docs/roadmap.md](docs/roadmap.md)；进展评估与后续安排（含待拍板事项）见 [docs/开发计划.md](docs/开发计划.md)。
>

请假管理（Phase 5）已完成：`/leave` 从占位页变为真实页面，覆盖**请假申请 → 审批 → 离校 / 返校登记**一条线。按「天 + 上午 / 下午」记录时段并自动算时长（半天 / 1 天 / 1 天半，跨月 / 跨年同样正确）；新增与编辑用右侧抽屉（选学生、类型（病假 / 事假 / 其他）、起止时段、原因；同一学生同时段已有记录**只提示不拦截**——准不准由班主任判断），审批走弹窗（批准 / 驳回，驳回可写说明、**批准不保存备注**），**已批准**的记录可登记离校与返校时间（记错可覆盖修改，不必删记录重建；登记的是既成事实，不能填未来的时间）。卡片上的「未离校 / 已离校 / 已返校」由两个时间戳**派生展示**，不新增第四种审批状态；列表支持搜索（姓名 / 学号后四位）与状态筛选（全部 / 待处理 / 已批准 / 已驳回），待处理置顶、已办按开始时间倒序。工作台的「请假审批」卡片显示待处理数与本月已批准人次，点开直达请假页。**学生被删除时记录保留**（姓名快照冻结），请假历史不会随档案清理而消失。数据保存在浏览器 localStorage（键 `teacherdesk:leaves`；仅在学生档案仍是示例数据时才播种示例记录），后端尚未接入。

自动排座（Phase 3D）已完成：**约束求解**——硬约束（不能同桌 / 不能相邻）必满足，无法满足则不生成方案并逐条说明冲突；软规则（坐后排 / 坐前排 / 同区块，取值域约束的三个预留规则位）尽量满足，未满足的部分由约束检查面板逐条提示；「高个」标签自动获得低权重后排偏好（显式规则优先）。生成结果落为**新方案**（原方案原样保留，可对比 / 可随时切回），支持「换一种排法」（换种子重排，沿用同一方案名不堆积）与「撤销」（切回原方案并删除新方案）。同一输入与种子结果确定（种子随机数 + 贪心 + 局部搜索，无外部依赖）。数据当前保存在浏览器 localStorage，后端尚未接入。

值日管理（Phase 6）已完成：`/duty` 从占位页变为**值日编排与轮换**页面，覆盖建组 → 设起点 → 每天自动排班一条线。值日组由教师**手动指定**组员（候选名单按学号排序、支持搜索，已不在档案的成员保留并标注，同一学生可在多组但会提示），**列表顺序就是轮换顺序**；轮换**按天**推进——设好「起点日期 + 起点组」后每天顺延一组、循环往复，**周末是否排值日**由教师开关决定（默认关＝周六周日不排、周一接着上一组继续，周末不消耗轮换位），起点落在周末或设为未来某天时都有明确的顺延 / 倒推口径，轮换说明与排出来的表同源。页面给出**今日值日**（组 + 组员）与**接下来 7 天**列表（周末标「不值日」、今天高亮）；起点组被删除时轮换自动顺延到下一组并提示重设。工作台新增全宽的**今日值日**卡片：今天的组 + 组员标签（最多 8 个，其余折叠）+「接下来：明天由「第 2 组」值日」，今天不值日时说明「周一继续轮到下一组」。**本阶段不做打卡与工位分工**，只做编排与轮换。数据保存在浏览器 localStorage（键 `teacherdesk:duty`；仅在学生档案仍是示例数据时才播种示例值日组），并已接入数据管理的备份 / 合并 / 概览 / 清空示例，后端尚未接入。

周末管理（Phase 7B，v0.11.0）已完成：`/weekend` 是**新的一级入口**，只回答一个问题——**这个周末谁返家了**。页面顶部是周末切换条（下周末 / 本周末 / 上周末，各标本期返家人数），分节头写明是哪个周末（如「本周末 · 9月12日 – 9月13日」）并给出**返家几人 / 留校几人**；下面按姓名升序列出本期返家名单，每行可撤销（二次确认）。点「登记返家」在抽屉里勾选学生即可，**候选名单是在读学生全员**，已登记的人显示「已登记」徽标并禁用勾选——两个入口重复登记同一人不会产生两条记录。**留校不建记录**：留校人数永远是「在读学生数 − 本期返家人数」算出来的，不会出现两个数各算各的；**不设审批**、**不记时长**、**不记离校 / 返校的具体时刻**，只记「这个周末是否返家」。工作台新增「周末返家」卡片（本期 + 人数 + 姓名标签 + 本月累计人次，点开直达）。**一个周末以该周周六的日期键标识**（周日登记归到前一天，周一到周五不能登记），不用「第几周」这种编号——避免跨年时归属算错。数据保存在浏览器 localStorage（键 `teacherdesk:weekendReturns`；仅在学生档案仍是示例数据时才播种示例记录），并已接入数据管理的备份 / 合并 / 概览 / 清空示例，后端尚未接入。

数据管理（近期增量，v0.9.0）已完成：`/toolbox` 从占位页变为**数据备份与恢复**入口。页面上先给出八个数据块的条目概览（学生档案 / 座位方案 / 座位约束 / 课程表 / 今日待办 / 请假记录 / 值日安排 / 周末返家），再是**导出备份（JSON）**（一键下载 `teacherdesk-backup-日期.json`，并记下「上次导出」时间）与**导入备份**。导入采用**合并式**：选择文件后先给出逐块预览（新增几条 / 覆盖几条 / 保持不变几条），确认后才写盘并重载——本机独有的记录原样保留、备份独有的追加、同一 id 以备份为准，**合并不会删除当前数据**；被覆盖的版本无法找回，弹窗内可直接「先导出当前备份」。危险操作区提供两档清空：**清空示例数据**（删除首次打开时自动生成的示例学生 / 课程 / 待办 / 请假及其座位约束，保留你自己录入的内容；确认弹窗会列出待删名单，因为按编号识别的示例记录若被你改成了自己的内容也会一并删除）与**清空全部数据**（恢复到首次打开的状态）。本机数据若某块读取异常，概览会显示「读取异常」，导入与清空示例都会跳过它，避免覆盖还能人工找回的原文。

稳定性增量（近期增量，v0.10.1）已完成：**不加新模块**，补两件事。① **工作台备份提醒**——首页新增一条提示：**从未导出过备份**时常驻「还没有导出过备份，数据只保存在这台设备上。」，**距上次导出满 14 天**转为醒目提示（写明已过天数与后果），点「去导出」直达 `/toolbox`，导出成功后立即消失；判定**只看「上次导出时间」这一个时间戳**，不做数据变更感知，也不会自动备份（宁可多提醒一次，也不漏）。② **PWA 正式 PNG 图标**——桌面 / 主屏图标由 SVG 占位换成四张正式 PNG（192 / 512 / 512 maskable 满幅 / apple-touch-icon 180），`favicon.svg` 保留；同时给 Service Worker 补上 `png` 匹配。另修掉 **8 处**「确认删除后弹窗 / 抽屉还在播淡出动画、名字已被清空」的显示缺陷（其中最扎眼的是课程抽屉标题会从「编辑课程」翻成「新增课程」），工具箱概览里未生成的模块改说「还没打开过」，清空全部数据时会明确告知旧课表存档一并删除。**既有数据零迁移**：只加提示与图标，未动存储结构与备份格式。

## 技术栈

| 类别       | 选型                                           |
| ---------- | ---------------------------------------------- |
| 框架       | Vue 3.5 + TypeScript 5.8（strict）             |
| 构建       | Vite 7                                         |
| 路由       | Vue Router 4                                   |
| 状态管理   | Pinia 3                                        |
| 原子化 CSS | UnoCSS（presetWind3，主题对接 theme.css 变量） |
| 图标       | @vicons/ionicons5（Ionicons，按需引入）        |
| PWA        | vite-plugin-pwa（autoUpdate）                  |
| 代码规范   | ESLint 9（flat）+ Prettier 3                   |

组件全部自行封装（不引入 UI 组件库），Apple 风格：主题色松石青 `#2F8F83`、16px 圆角、毛玻璃、柔和阴影。Design Tokens 统一维护在 `src/styles/theme.css`。

## 启动方式

```bash
# 安装依赖（Node.js >= 20.19）
npm install

# 本地开发（http://localhost:5173）
npm run dev
```

常用命令：

```bash
npm run dev         # 开发服务器
npm run type-check  # TypeScript 类型检查（vue-tsc --noEmit）
npm run lint        # ESLint 检查并自动修复
npm run format      # Prettier 格式化
npm run build       # 类型检查 + 生产构建
npm run preview     # 预览生产构建（验证 PWA 安装用）
```

## 基础组件（`src/components/ui/`）

AppCard / AppButton / AppInput / AppTextarea / AppSelect / AppField / AppBadge / AppModal / AppDrawer / AppSwitch / AppToast / EmptyState，统一由 `@/components/ui` 出口导入（弹层的滚动锁 / 层级栈 / 焦点陷阱在 `ui/layers.ts`，Modal 与 Drawer 共用）。

全局通知（AppToast 已在 `App.vue` 挂载）：

```ts
import { useToast } from '@/composables/useToast'
const toast = useToast()
toast.success('保存成功')
toast.danger('同步失败，请重试')
```
