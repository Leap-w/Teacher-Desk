## 身份认证

1. **用户名登录**（当前线上账号用的就是这条）：控制台 → 身份认证 → 登录方式 → 打开「用户名密码」。
2. **邮箱登录**（Cloud-3 的「我的 → 云端同步 → 登录云端」用这条）：同一页打开「邮箱密码」。
   - **建账号时把「邮箱验证」关掉**（或设为「验证链接」，别用「验证码」）：应用里没有输入验证码的地方，
     账号停在未验证状态时登录必被拒。
3. 建账号：身份认证 → 用户管理 → 新建用户。**TeacherDesk 只有一个账号（班主任本人）**——
   不做邀请码、不做多用户、不做学生账号。
4. 若关闭了「首次登录强制改密」：项目曾因这条策略导致首次登录被拒
   （`FIRST_LOGIN_PASSWORD_UPDATE_REQUIRED`），应用里没有改密界面，建议保持关闭。

## 数据库

- 集合：`teacherdesk`（一个集合，文档 ID 就是本机存储键名）。
- 权限：**仅创建者可读写**（`auth.uid == doc._openid` 一类规则由控制台模板直接给）。
- 文档形状（与 `services/remote.ts` 的 `RemoteDoc` 一致）：

| 字段        | 用途                                                       |
| ----------- | ---------------------------------------------------------- |
| `key`       | 文档 ID（= 本机存储键名，如 `teacherdesk:students`）       |
| `payload`   | 整份数据（一个数组，与 localStorage 里那份同形）           |
| `updatedAt` | 写入方的时间戳（毫秒）——**最后写入胜出（LWW）** 靠它比大小 |
| `userId`    | 当前账号（安全规则与诊断用；由 SDK 会话隐式绑定）          |
| `version`   | 预留（当前未使用；将来做字段级合并时启用）                 |

## 静态托管

- 已开通；`npm run deploy` 走 `cloudbaserc.json` 声明式部署。
- **安全来源**：环境配置 → 安全来源里要包含默认域名，否则页面能开、登录与同步会被云端拒。
- 已知两项（不影响功能）：未启用 gzip（入口 chunk 传原始体积）、默认 `cache-control: no-store`。

## 本机同步相关键（不属于云端配置，诊断时对照）

| 键                         | 用途                                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| `teacherdesk:cloud:meta`   | 每个键的**对齐记账**（上次同步后的原文 / 对齐时刻 / 本机写盘时刻）——LWW 与首次保护的依据；登出即清 |
| `teacherdesk:sync-queue`   | **待同步队列快照**（Cloud-4）：刷新 / 关标签 / 重启后据此续传；推成功即出队并落盘为空              |
| `teacherdesk:localWriteAt` | 每个键最后一次真的写盘的时刻                                                                       |
| `teacherdesk:seedText`     | 播种基线（识别「本机这份只是示例数据」）                                                           |

以上四个键**都不参与云同步**（不是教师的数据），但会随「清空本机数据」一起被清掉。

## 同步语义（应用侧，不属于控制台配置）

- **Local First**：localStorage 永远是主缓存，断网照常用；写盘即入队，联网自动补推。
- **Last Write Wins**：按 `updatedAt` / 本机写盘时刻比较，新覆盖旧。单用户场景不做字段级合并。
- **首次同步四态**：空→正常开始；本机有云端空→**问一句**是否初始化云端；云端有本机空→直接拉；两边都有→逐键裁决（工具箱）。
- 队列与重试由 `src/sync/SyncEngine.ts` 负责（重试上限 3 次、退避、失败不堵死其它键）。
