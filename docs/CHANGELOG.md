## v0.9.0 —— 近期增量：数据管理（Data Management）（2026-09-10，commit `feat: data management (backup export / merge import / clear)`）

`/toolbox` 由占位页升级为**数据备份与恢复**入口：**导出备份 → 合并导入 → 清空示例数据 / 清空全部数据**。localStorage「一清即空」的红灯级风险由此转为可控。

> 编号：这不是路线图（开发手册 §10）中的一个 Phase，而是 Phase 6 之前的**近期增量**（排期见 `docs/开发计划.md` §六）。以 tag 为准。

### 新增

- **`/toolbox` 数据管理页**：六个数据块的条目概览（学生档案 / 座位方案 / 座位约束 / 课程表 / 今日待办 / 请假记录）+ 导出备份（JSON）+ 导入备份 + 「上次导出」时间；危险操作区提供两档清空。
- **导出备份**：把六个 `teacherdesk:*` 数据块原样打包为单个 JSON（含应用名 / 结构版本 / 应用版本 / 导出时间），文件名 `teacherdesk-backup-YYYY-MM-DD.json`；导出成功后记录「上次导出」时间（该提示状态本身不在备份内）。
- **导入备份（合并式）**：选择 JSON → 校验（是否本应用备份 / 结构版本是否过新 / 每块是否为列表）→ **逐块预览「新增 / 覆盖 / 保持不变」** → 确认后写盘并重载。合并规则：本机独有的记录原样保留、备份独有的追加到末尾、同一 id 以备份为准——**合并从不删除当前数据**；备份里没有的数据块不参与合并。
- **清空示例数据**：一键删除首次打开时播种的示例记录（示例学生 / 课程 / 待办 / 请假）及这些学生产生的座位约束，保留教师自己录入的内容；确认弹窗**列出待删名单**（姓名 / 「周X 第N节 科目」/ 待办正文），座位方案与换座日志保留。
- **清空全部数据**：删除本应用前缀下的全部键（按前缀扫描，含未来的新键），重载后回到首次打开的状态（示例数据重新出现）。
- **数据层** `utils/backup.ts`：`BACKUP_MODULES`（六个键的单一登记处）+ `readModules` / `countModules` + `createBackup` / `parseBackup` + `planMerge` / `planClearSamples`（纯函数，先算后写）+ `applyWrites` / `clearAllKeys`（整批原子写）+ `downloadJson`；`utils/id.ts` 新增 `isSampleRecordId`（示例记录的 id 前缀识别）。

### 修复（交付前两轮独立审查：正确性 + 文档 / UX，共 16 项全部处理；无阻塞项）

- **【中】本应用自己的备份可能导不回来**：导出时原样收录条目、导入却要求「每条都有 id」并整份拒绝——而 student 的 `normalize` 不补 id，无 id 记录可以长期存在。改为**缺 id 条目照常导入**（追加到末尾、不参与按 id 合并）并在预览里说明，宁可重复一条也不丢。
- **【中】本机某块读取异常时会被静默当成空、并被备份整块覆盖**：损坏块现在在概览里显示「读取异常」，导入与「清空示例数据」都**跳过该块**（绝不写盘），以免覆盖还能人工找回的原文。
- **【中】写盘非原子，失败提示「数据未改变」可能是假话**：写入改为整批原子提交，中途失败即回滚；回滚成功提示「已恢复为操作前的数据」，回滚也失败则如实提示「本机数据可能不完整，请立刻刷新检查」；`reload` 移出写盘 try，避免「写成功却报失败」。
- **【中】导入是不可逆覆盖，却没有「先导出」的提示**：与「清空全部数据」口径对齐——弹窗写明「被覆盖的版本无法找回」，并提供「先导出当前备份」按钮（不关闭弹窗即可导出）。
- **【中】「你自己录入的内容不受影响」在改造过的示例记录上不成立**：示例识别按 id 前缀，教师把示例课直接改成自己的课也会被删。确认弹窗改为**列出待删名单**并明示「已改成自己内容的示例记录同样会被删除」，危险区文案同步；根治方案（给种子记录加标记字段）记入技术债。
- **【低】**：「没有可合并的记录」时确认按钮仍可点 → 一并禁用；清空全部数据的成功提示「N 个数据块」与实际列表对不上 → 去掉数字、列表过滤 0 条并标出「读取异常」块；导出失败无任何提示 → 补 toast；错误文案里的开发者词汇（「顶层」「列表」「缺少 id」）改为教师能看懂的说法；`teacherdesk:notice` 未走 `storageKeyPrefix`（补齐）；面向教师的页面上出现仓库路径（移除）；合并表补 `scope="col"`；隐藏的文件选择框补 `aria-hidden`；表格间距改取 token。
